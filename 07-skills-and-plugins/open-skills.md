## ⚡ 实战指南：如何把神级 Skill 塞进你的 Agent？

新手面对上面成百上千的技能库往往无从下手。其实在 2026 年，所谓的“Skill（技能）”通常只有两种最简形态，扒下来极其容易：

### 形态 1：纯 Prompt / Markdown 形态 (如 `taste-skill` / `CLAUDE.md`)
这类技能本质上是写得极其精妙的**系统指令**。
- **怎么用**：直接进入该项目的 GitHub 仓库，找到 `.md` 或 `.txt` 文件，把它复制并粘贴到你的 Cline 的 `Custom Instructions` 里，或者放到你项目根目录的 `CLAUDE.md` 中。你的 AI 瞬间就具备了“顶级设计师的审美”或“高级架构师的代码规范”。

### 形态 2：MCP Server 形态 (如各种自动化发推、搜索技能)
这类技能通常是一个包含具体执行代码的项目包。
- **怎么用**：在你的 IDE（如 Cursor）的 MCP 配置面板中，将该技能仓库以 `npx` 或本地 Python 脚本的形式挂载进去。AI 在需要时会自动通过协议调用这些“外挂动作”。
