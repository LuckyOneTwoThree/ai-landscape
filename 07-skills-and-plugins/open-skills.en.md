## ⚡ Practical Guide: How to Inject God-tier Skills into Your Agent?

Beginners are often at a loss when faced with hundreds or thousands of skills libraries like those above. In fact, in 2026, so-called "Skills" typically take only two simplest forms and are extremely easy to acquire:

### Form 1: Pure Prompt / Markdown Form (e.g., `taste-skill` / `CLAUDE.md`)
These skills are essentially exquisitely written **system instructions**.
- **How to use**: Go directly to the GitHub repository of the project, find the `.md` or `.txt` file, copy and paste it into your Cline's `Custom Instructions`, or place it in the `CLAUDE.md` in your project's root directory. Your AI will instantly possess "top-tier designer aesthetics" or "senior architect coding standards."

### Form 2: MCP Server Form (e.g., automated tweeting, search skills)
These skills are usually project packages containing specific executable code.
- **How to use**: In the MCP configuration panel of your IDE (e.g., Cursor), mount the skill repository as an `npx` or local Python script. When needed, the AI will automatically call these "plugin actions" via the protocol.
