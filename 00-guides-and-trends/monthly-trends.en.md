## Major Ecosystem Changes

### 1. OpenAI ChatGPT "Superapp" Revamp
- **"Chat is dead"**: OpenAI executives indicated that the chat paradigm is outdated.
- Fully pivoting to coding, image generation, and external application ecosystems.
- Encouraging users to utilize Codex, image generation, and third-party apps.

### 2. GitHub Copilot Pay-As-You-Go
- Transitioned from fixed subscription to pay-as-you-go billing.
- Strong user reactions, with some reporting significantly increased costs.
- Reflects the cost pressure on AI coding tools.

### 3. Apple Siri AI Major Upgrade
- WWDC 2026 announced a comprehensive upgrade to Siri AI.
- Deep integration with Apple Intelligence.
- Running on NVIDIA GPUs + Google Cloud.
- Delayed launch in the EU due to DMA regulations.

### 4. Google NotebookLM Upgrade
- Upgraded to Gemini 3.5.
- Added cloud computer features.
- Intelligent source search capabilities.

## Trend Directions

1. **Agents as the Core**: GPT-5.5, Claude Opus 4.8, and Gemini 3.5 all feature Agent capabilities as their core selling point.
2. **Explosion of Coding Agents**: Tools like Codex, Claude Code, and Cursor are comprehensively transitioning to Agentic paradigms.
3. **Computer Use as Standard**: GPT-5.5 OSWorld 78.7%, Claude Opus 4.8 Online-Mind2Web 84%.
4. **Multi-Agent Coordination**: Gemini 3.5 focuses on multi-Agent workflows.
5. **Cost Pressures Emerging**: The GitHub Copilot pricing reform reflects cost issues for AI tools.
6. **Continuous Catch-Up by Chinese Models**: DeepSeek V4, GLM-5.1, and Kimi K2-6 have all reached frontier levels.
7. **MCP as the De Facto Standard**: Supported by all mainstream IDEs/frameworks.
8. **A2A Protocol Released**: Google released the Agent-to-Agent protocol, driving Agent interoperability.
